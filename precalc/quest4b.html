Quest 5: Logarithmic and Exponential Encodings

Directions: Solve each problem and enter the requested encoded value.

Read each problem carefully. You are not always entering the solution itself. You are entering the value requested at the end of the problem.

  1. Consider \(f(x)=\ln(x-5)+11\). The inverse of \(f\) can be written as \(e^{x-a}+b\), where \(a\) and \(b\) are prime numbers. Find \(ab\).
  2. Consider \(f(x)=\ln(x-7)+3\). The inverse of \(f\) can be written as \(e^{x-a}+b\), where \(a\) and \(b\) are prime numbers. Find \(ab\).
  3. Consider \(f(x)=\ln(x-2)+17\). The inverse of \(f\) can be written as \(e^{x-a}+b\), where \(a\) and \(b\) are prime numbers. Find \(ab\).
  4. Consider the equation \(e^{2x}+6e^x=14\). The solution can be written as \(\ln(\sqrt{a}-b)\), where \(a\) and \(b\) are prime numbers. Find \(ab\).
  5. Consider the equation \(e^{2x}+10e^x=46\). The solution can be written as \(\ln(\sqrt{a}-b)\), where \(a\) and \(b\) are prime numbers. Find \(ab\).
  6. Consider the equation \(e^{2x}+14e^x=64\). The solution can be written as \(\ln(\sqrt{a}-b)\), where \(a\) and \(b\) are prime numbers. Find \(ab\).
  7. Consider the equation \(e^{2x}+22e^x=52\). The solution can be written as \(\ln(\sqrt{a}-b)\), where \(a\) and \(b\) are prime numbers. Find \(ab\).
  8. Consider the equation \(\ln(x-4)+\ln(x+2)=\ln(10)\). The solution can be written as \(a+b\sqrt{c}\), where \(c\) is square-free. Find \(a+b+c\).
  9. Consider the equation \(\ln(x-5)+\ln(x+1)=\ln(30)\). The solution can be written as \(a+b\sqrt{c}\), where \(c\) is square-free. Find \(a+b+c\).
  10. Consider the equation \(\ln(x-7)+\ln(x+3)=\ln(36)\). The solution can be written as \(a+b\sqrt{c}\), where \(c\) is square-free. Find \(a+b+c\).
  11. Consider the equation \(\ln(x-6)+\ln(x+2)=\ln(25)\). The solution can be written as \(a+b\sqrt{c}\), where \(c\) is square-free. Find \(a+b+c\).
  12. Consider the equation \(\ln(x-8)+\ln(x+2)=\ln(64)\). The solution can be written as \(a+b\sqrt{c}\), where \(c\) is square-free. Find \(a+b+c\).
  13. Consider the equation \(\ln(x-9)+\ln(x+1)=\ln(49)\). The solution can be written as \(a+b\sqrt{c}\), where \(c\) is square-free. Find \(a+b+c\).
  14. Consider the equation \(\ln(x-7)+\ln(x+1)=\ln(13)\). The solution can be written as \(a+b\sqrt{c}\), where \(c\) is square-free. Find \(a+b+c\).
  15. Consider the equation \(\ln(x-10)+\ln(x+4)=\ln(64)\). The solution can be written as \(a+b\sqrt{c}\), where \(c\) is square-free. Find \(a+b+c\).
