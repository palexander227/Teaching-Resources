Practice Test A — Solutions

Complete worked solutions to the four problems on Practice Test A.

Problem 1

Given

\[ f(x)=-\frac{4}{x^2-3x}=-\frac{4}{x(x-3)} \]

To find the vertical asymptotes, set the denominator equal to zero:

\[ x(x-3)=0 \]

So the function is undefined at

\[ x=0,\quad x=3 \]

Therefore the vertical asymptotes are

\[ \boxed{x=0 \text{ and } x=3} \]

Since the degree of the denominator is greater than the degree of the numerator, the horizontal asymptote is

\[ \boxed{y=0} \]

Now find the relative minimum. Differentiate:

\[ f(x)=-4(x^2-3x)^{-1} \]

\[ f'(x)= -4(-1)(x^2-3x)^{-2}(2x-3) = \frac{4(2x-3)}{(x^2-3x)^2} \]

Critical points occur when the numerator is zero:

\[ 2x-3=0 \implies x=\frac{3}{2} \]

Evaluate the function there:

\[ f\left(\frac{3}{2}\right) = -\frac{4}{\left(\frac{3}{2}\right)^2-3\left(\frac{3}{2}\right)} = -\frac{4}{\frac{9}{4}-\frac{9}{2}} = -\frac{4}{-\frac{9}{4}} = \frac{16}{9} \]

So the relative minimum is

\[ \boxed{\left(\frac{3}{2},\frac{16}{9}\right)} \]

Now find the range. Let

\[ y=-\frac{4}{x^2-3x} \]

Then

\[ yx^2-3yx+4=0 \]

This is a quadratic in \(x\). For real solutions, its discriminant must be nonnegative:

\[ (-3y)^2-4(y)(4)\ge 0 \]

\[ 9y^2-16y\ge 0 \]

\[ y(9y-16)\ge 0 \]

Thus

\[ y\le 0 \quad \text{or} \quad y\ge \frac{16}{9} \]

But \(y=0\) is impossible because the numerator is never zero. Therefore the range is

\[ \boxed{(-\infty,0)\cup\left[\frac{16}{9},\infty\right)} \]

Graph behavior summary:
  • As \(x\to -\infty\), \(f(x)\to 0^{-}\)
  • As \(x\to 0^{-}\), \(f(x)\to -\infty\)
  • As \(x\to 0^{+}\), \(f(x)\to +\infty\)
  • On \((0,3)\), the graph is positive and reaches its minimum at \(\left(\frac{3}{2},\frac{16}{9}\right)\)
  • As \(x\to 3^{-}\), \(f(x)\to +\infty\)
  • As \(x\to 3^{+}\), \(f(x)\to -\infty\)
  • As \(x\to \infty\), \(f(x)\to 0^{-}\)
Final answers:
Vertical asymptotes: \(\boxed{x=0,\ x=3}\)
Horizontal asymptote: \(\boxed{y=0}\)
Relative minimum: \(\boxed{\left(\frac{3}{2},\frac{16}{9}\right)}\)
Range: \(\boxed{(-\infty,0)\cup\left[\frac{16}{9},\infty\right)}\)

Problem 2

Given

\[ y=2+\frac12\cos\left(-4\theta-\frac{\pi}{4}\right) \]

Since cosine is even, \(\cos(-u)=\cos(u)\), we may rewrite this as

\[ y=2+\frac12\cos\left(4\theta+\frac{\pi}{4}\right) \]

Factor the inside:

\[ 4\theta+\frac{\pi}{4} = 4\left(\theta+\frac{\pi}{16}\right) \]

So the equation becomes

\[ y=2+\frac12\cos\left(4\left(\theta+\frac{\pi}{16}\right)\right) \]

From this form we obtain:

  • Amplitude: \(\boxed{\frac12}\)
  • Period: \(\displaystyle \frac{2\pi}{4}=\boxed{\frac{\pi}{2}}\)
  • Phase shift: \(\boxed{\text{left } \frac{\pi}{16}}\)
  • Vertical shift: \(\boxed{2}\)
  • Midline: \(\boxed{y=2}\)

The maximum value is

\[ 2+\frac12=\boxed{\frac52} \]

The minimum value is

\[ 2-\frac12=\boxed{\frac32} \]

There are no vertical asymptotes for cosine, so

\[ \boxed{\text{no vertical asymptotes}} \]

The transformations from the basic graph \(y=\cos\theta\) are:

  1. Horizontal compression by factor \(4\)
  2. Shift left by \(\frac{\pi}{16}\)
  3. Vertical shrink by factor \(\frac12\)
  4. Shift up by \(2\)

A convenient cycle starts where the cosine graph begins at a maximum, namely at

\[ \theta=-\frac{\pi}{16} \]

The quarter-period is

\[ \frac14\cdot \frac{\pi}{2}=\frac{\pi}{8} \]

So one cycle may be plotted with the five key points:

\[ \left(-\frac{\pi}{16},\frac52\right),\quad \left(\frac{\pi}{16},2\right),\quad \left(\frac{3\pi}{16},\frac32\right),\quad \left(\frac{5\pi}{16},2\right),\quad \left(\frac{7\pi}{16},\frac52\right) \]

Final answers:
Amplitude: \(\boxed{\frac12}\)
Period: \(\boxed{\frac{\pi}{2}}\)
Phase shift: \(\boxed{\text{left } \frac{\pi}{16}}\)
Vertical shift: \(\boxed{2}\)
Minimum value: \(\boxed{\frac32}\)
Maximum value: \(\boxed{\frac52}\)
Vertical asymptotes: \(\boxed{\text{none}}\)

Problem 3

Given

\[ A=30^\circ,\qquad a=7,\qquad b=10 \]

This is the SSA ambiguous case, so we first check how many triangles are possible.

Compute the altitude:

\[ h=b\sin A=10\sin 30^\circ=10\cdot \frac12=5 \]

Now compare:

\[ h=5,\qquad a=7,\qquad b=10 \]

Since

\[ h<a<b \]

there are two possible triangles.

Use the Law of Sines:

\[ \frac{\sin B}{b}=\frac{\sin A}{a} \]

\[ \frac{\sin B}{10}=\frac{\sin 30^\circ}{7} \]

\[ \sin B=\frac{10\cdot \frac12}{7}=\frac57 \]

So one possible angle is

\[ B_1=\sin^{-1}\left(\frac57\right)\approx 45.585^\circ \]

The second possible angle is

\[ B_2=180^\circ-45.585^\circ\approx 134.415^\circ \]

Case 1

\[ B\approx 45.585^\circ \]

Then

\[ C=180^\circ-30^\circ-45.585^\circ\approx 104.415^\circ \]

Use the Law of Sines again:

\[ \frac{c}{\sin C}=\frac{a}{\sin A}=\frac{7}{\sin 30^\circ}=14 \]

Hence

\[ c=14\sin(104.415^\circ)\approx 13.56 \]

So one triangle is

\[ \boxed{B\approx 45.585^\circ,\quad C\approx 104.415^\circ,\quad c\approx 13.56} \]

Case 2

\[ B\approx 134.415^\circ \]

Then

\[ C=180^\circ-30^\circ-134.415^\circ\approx 15.585^\circ \]

Again,

\[ c=14\sin(15.585^\circ)\approx 3.76 \]

So the second triangle is

\[ \boxed{B\approx 134.415^\circ,\quad C\approx 15.585^\circ,\quad c\approx 3.76} \]

Final answer:
There are two possible triangles:

\(\boxed{B\approx 45.585^\circ,\ C\approx 104.415^\circ,\ c\approx 13.56}\)

or

\(\boxed{B\approx 134.415^\circ,\ C\approx 15.585^\circ,\ c\approx 3.76}\)

Problem 4

Let

  • \(B\) = foot of the tower
  • \(T\) = top of the tower
  • \(P\) = point down the road

Then

\[ BT=23.5\text{ m},\qquad BP=28.2\text{ m},\qquad \angle B=110.2^\circ \]

We want the angle subtended by the tower at point \(P\), that is, \(\angle P\).

Use the Law of Cosines to find \(TP\):

\[ TP^2=BT^2+BP^2-2(BT)(BP)\cos(110.2^\circ) \]

\[ TP^2=23.5^2+28.2^2-2(23.5)(28.2)\cos(110.2^\circ) \]

\[ TP^2\approx 1805.148 \]

\[ TP\approx 42.487 \]

Now use the Law of Sines:

\[ \frac{\sin P}{23.5}=\frac{\sin 110.2^\circ}{42.487} \]

So

\[ \sin P=\frac{23.5\sin 110.2^\circ}{42.487} \]

\[ P\approx 31.27^\circ \]

Final answer:
The angle subtended by the tower is \[ \boxed{31.3^\circ} \]
