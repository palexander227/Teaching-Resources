Core prompt library

The 12 patterns every AI operator needs

Prompt patterns should be taught as reusable work structures, not magic phrases.

1. The Work Order

Objective → context → constraints → output → quality standard

2. Rubric First

Ask the model to define the evaluation rubric before producing the artifact.

3. Draft-Critique-Revise

Generate a first draft, critique against a rubric, then produce a revised version.

4. Socratic Tutor

Teach through questions, diagnose misconceptions, and avoid simply giving answers.

5. Source-Grounded Research

Require source ranking, citation discipline, uncertainty flags, and separation of facts from inference.

6. Extraction Schema

Convert messy documents into structured fields, with missing-value and confidence labels.

7. Red-Team Review

Ask the model to find errors, hidden assumptions, weak evidence, and client objections.

8. Workflow Decomposition

Break a large project into phases, dependencies, commands, risks, and artifacts.

9. Agent Brief

Specify mission, scope, files, permissions, checkpoints, stop conditions, and acceptance criteria.

10. Style Transfer With Constraints

Rewrite content in a target voice while preserving factual claims and technical precision.

11. Cost/Risk Preflight

Estimate token cost, data sensitivity, tool permissions, and verification burden before a run.

12. Teach-Back

Have the model explain what it did, what it assumed, and what a human should check next.

Reusable master prompt template
You are helping me complete a real professional task. Objective: [state the concrete outcome] Audience: [who will read/use this] Context: [project background, files, prior decisions] Constraints: [tone, format, length, tools, confidentiality] Output: [exact artifact type and structure] Quality standard: [what would make this excellent] Verification: identify assumptions, uncertainty, missing information, and what I should check manually before using the result.

Long-running work

Agentic delegation without losing control

Autonomous AI work can save hours, but it can also drift, spend tokens, overwrite files, or solve the wrong problem. The course teaches controlled delegation.

Agent Brief Checklist

  • Mission: the exact outcome.
  • Repository or file scope.
  • Allowed tools and forbidden actions.
  • Checkpoints and progress reports.
  • Budget and time ceiling.
  • Acceptance criteria and tests.
  • Rollback plan.

Cost and privacy rule

Long-running agentic work should be treated like a paid contractor with access to sensitive materials. Estimate token cost, check retention terms, restrict file access, and require summaries before major changes.

Cost-estimation formula for API or agentic work

Use this before launching large repository audits, document-ingestion tasks, or long-running coding agents.

Estimated cost = (input_tokens / 1,000,000 × input_rate) + (output_tokens / 1,000,000 × output_rate) + tool charges + runtime/session charges + rerun buffer Recommended rerun buffer: 25% to 100%, depending on task uncertainty.
Quality control

The verification ladder

Students learn that AI output has different assurance levels. Not every answer deserves the same trust.

Level 1
Draft

  • Useful for brainstorming.
  • No external verification.
  • Not client-ready.

Level 2
Structured

  • Clear format.
  • Assumptions listed.
  • Human review required.

Level 3
Sourced

  • Sources cited.
  • Claims traceable.
  • Factual risk reduced.

Level 4
Audited

  • Red-team pass.
  • Reproducible steps.
  • Ready for professional use.

First workshop exercise

The 30-minute demonstration

This is the live demo to open the course. It immediately shows why disciplined AI use beats casual prompting.

Bad prompt

Make me a report about AI tools.

Students observe the weaknesses: vague scope, no audience, no quality standard, no sources, no output structure.

Operator prompt

Prepare a two-page executive brief for school administrators deciding whether to offer an AI literacy workshop. Include: the practical opportunity, the academic integrity risk, three recommended policies, a teacher training plan, and a one-paragraph implementation timeline. Use calm professional language. Flag assumptions and identify what should be verified before sending.

Students see the difference: objective, audience, structure, constraints, verification, and professional output.
